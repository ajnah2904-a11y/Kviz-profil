### 💻 Tehnologije:
* **HTML5** za strukturu
* **CSS3** za moderan Dark Mode dizajn
* **JavaScript** za logiku profilisanja

### 🏫 O smjeru:
Predstavljamo IT smjer **Prve gimnazije Sarajevo**. Fokusiramo se na programiranje, baze podataka i razvoj kreativnih rješenja.
